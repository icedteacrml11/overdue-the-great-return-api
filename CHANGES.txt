PROBLEM
-------
All database-related npm scripts were failing:

  npm run db:create
  npm run db:migrate
  npm run db:migrate:status
  npm run db:seed
  npm run db:check

The error was:
  ERROR: Error reading "src\config\database.js".
  Error: SyntaxError: Invalid or unexpected token

ROOT CAUSE
----------
Template literals (backtick characters `) were corrupted across multiple source
files. Instead of proper JavaScript template literals like:

  `Hello ${name}`

the files contained backslashes:

  \Hello \

This caused Node.js to throw a SyntaxError whenever it tried to parse any file
in the require chain starting from src/config/database.js -> src/config/env.js.

Additionally, the .env file had a placeholder password (your_postgres_password_here)
instead of the actual PostgreSQL password.
